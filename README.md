part1_3.ipynb: This script simulates the orbits of our solar system's eight planets to calculate their exact orbital periods and compares them against real NASA data. Using NumPy for array calculation and handling, the code initializes each planet at its aphelion, the point furthest from the Sun with a starting velocity calculated from vis-viva equation. The core part of the simulation is the 4th-Order Runge-Kutta (RK4) function, which calculates the Sun's gravitational pull at each tiny time step and returns the planet's newly updated state specifically, its new position (x, y) and velocity (vx, vy) for the next state Because RK4 moves the planet in discrete jumps, the planet will step slightly past the exact finish line of a full orbit (y=0). To fix this, the script tracks the y-coordinate and uses linear interpolation to calculate the precise fraction of that final step where the planet actually crossed the line. Once that exact finish time is found, the code outputs a table showing how closely our simulated time period matches the actual observed one with absolute error. (LLM was used to get the table like structure and also it suggested the linear interpolation to get accurate time period) 

part2_1(1).ipynb: This notebook tests Kepler's Third Law on the eight planets of our solar system. In units of AU, years and solar masses (GM = 4pi^2), the law T^2 = a^3 becomes a straight line when we take logs of both sides: log(T) = 1.5 log(a), so the slope should be exactly 1.5 and the intercept 0. Using the semi-major axes and observed periods from the NASA Planetary Fact Sheet, along with the simulated periods from part1_3.ipynb, the code takes log10 of a and T and fits a straight line using the least-squares formulas written out in NumPy (slope = Sxy/Sxx, intercept = mean(y) - slope*mean(x)). It then calculates the standard error of the slope from the residuals, dividing by n-2 = 6 degrees of freedom since two parameters (slope and intercept) are estimated from 8 data points. Because we only have 8 points, the 95% confidence interval is built using the t-distribution (t = 2.447 for 6 degrees of freedom, taken from scipy.stats) instead of the usual 1.96. The observed data gives a slope of 1.49896 with a 95% confidence interval of [1.49784, 1.50007], so 1.5 lies inside and the planets are consistent with Kepler's law, while the simulated periods give a slope of 1.4999998, confirming our RK4 integrator. Finally, matplotlib is used to plot log(T) vs log(a) with the fitted line and a residual plot, which shows Saturn as the largest outlier because the semi-major axis value used differs from NASA's long-term mean value. The code uses the libraries numpy, matplotlib and scipy.
